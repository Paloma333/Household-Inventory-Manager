> 版本：v1.0 · 2026-08-19
> 交付对象：K3（视觉设计 AI）
> 一句话任务：把一个已功能完整的库存管理 Web 应用「小家」，从当前的「米白纸感」气质，整体升级为「动森（Animal Crossing: New Horizons）式治愈小岛」气质。**只改视觉，不动功能、不动信息架构、不动组件接口。**

## 0. 你是谁

你是 K3，资深产品视觉设计师，审美锚点是任天堂《集合啦！动物森友会》（Animal Crossing: New Horizons，下称动森）的 UI 语言——柔和、圆润、木质、治愈，但**保持工具可用性**。你擅长把游戏化气质克制地翻译成生产力界面。

「小家」是一个家庭库存管理应用：拍小票 / 截图让 AI 识别商品入库，管理库存数量、保质期、补货清单。目前功能全部完成（Next.js + Tailwind + 一套 CSS design token），等待视觉升级。

你负责产出：

1. **一套可直接替换的 design token 改版**（CSS 变量，对应现有 `app/globals.css` 的 `:root` 与 dark 块）
2. **10 个基础组件的逐条视觉规格**
3. **12+ 个页面的逐页改造说明**
4. **（推荐）3 个关键页面的独立 HTML mockup**：首页 / AI 确认页 / 库存列表（移动端优先，390px 宽度）

### 3.3 材质 / 形状 / 字体 / 动效

**材质（纯 CSS 模拟，禁止大图）**
- 页面底：米白 + `radial-gradient` 草点纹理（现有实现保留，颜色随新 token）；暗色版换成「萤火虫」亮点。
- 卡片：纸/浅木底 + 1px 细描边；**关键卡片**（低库存、确认弹窗）升级为「动森对话气泡」——白底 + 2px 深棕描边 + 圆角 + 底部小三角尾巴。
- 木牌标题：页面标题用「木牌」样式（浅木底 `--wood-soft` + 木色描边 + 圆角），可选小钉子点缀。

**形状与圆角（更圆，但保留节奏）**
```
--radius-xs: 8px;     /* chip */
--radius-sm: 12px;    /* 输入框 */
--radius-md: 16px;    /* 普通卡片 */
--radius-lg: 24px;    /* 大卡片 / 浮层 */
--radius-pill: 999px; /* 按钮 / 头像 */
```

**字体**
- 中文标题（欢迎语、卡片标题、木牌）：启用 `LXGW WenKai`（霞鹜文楷）——`app/globals.css` 里已注释好 @font-face，打开即可，用 woff2 自托管或 CDN。
- 正文：保持系统 sans（PingFang SC 等），字号阶梯按 PRD 不动。
- 数字：保持 `Inter` + tabular-nums。

**动效（动森版）**
- 主缓动：保留现有 `ease-out-expo`；**新增一个 `--ease-pop: cubic-bezier(0.34, 1.56, 0.64, 1)`**，仅用于元素入场（scale 0.96→1.0 + 淡入，≤ 280ms）。动森的「轻微回弹」只体现在这里，**不要**应用到列表滚动或连续动画。
- 按钮按下：scale 0.96 + 「厚边消失内陷」效果（见组件 Btn）。
- 数字滚动、骨架屏、撤销 toast 等既有规则全部保留（PRD §4）。

**图标（手绘风，动森化）**
- 统一 2px 深棕描边（`--border-outline`）、圆角端点、圆润造型；现行 1.5px 太细。
- 标志性点缀元素（克制使用）：四叶草/叶片、铃钱袋、木牌、气球、星星碎片。
- 点缀元素只出现在：空状态插画、成功过渡页、首页角落装饰、FAB。**禁止** emoji 代替图标。
- 保留现有 lucide 图标库，通过 `stroke-width: 2` + 描边色 token 实现，不换库。

**文案**
- 语气保持 PRD §1.5（第一/二人称、鼓励式、口语化数字单位），**可微调但不卖萌**。
- 允许个别页面用动森口吻的欢迎语，如首页「欢迎回到小家」（不改语义，只换说法）。

## 4. 硬约束（不许破坏）

1. **只改视觉**。组件文件名、prop、数据流、路由一律不动；CSS 变量**语义名不许改**（`--bg-canvas` 等），只能改值 + 新增（如 `--border-outline`）。
2. **信息密度不降**。库存数字、列表可读性优先于装饰；装饰元素最多占页面面积 5%。
3. **不要每页塞动物角色**。动森感来自色彩/材质/描边/图标，不是吉祥物轰炸；全站最多允许 1 个角色化元素（建议只在 landing 或成功页出现）。
4. **可访问性**：正文对比度 ≥ 4.5:1、大字 ≥ 3:1（WCAG AA）；触控目标 ≥ 44px；颜色不是唯一信息载体（低库存必须有文字标签）。
5. **深色模式必须同步设计**，不能只是 Light 的取反。
6. **移动端优先**（390px 基准），桌面端只是加宽，不重排。
7. 动效总时长 ≤ 280ms/次；不用 1s+ 入场动画；不用果冻式回弹滥用。

## 5. 逐组件改造点

| 组件 | 动森版视觉规格 |
|---|---|
| **Btn** | primary：叶绿填充 + 米白文字 + pill 圆角 + 2px 深棕描边 + **底部 3px 深一档厚边**（按钮「立起来」感）；按下：scale 0.96 + 厚边消失（内陷感）。secondary：木纸底 `--wood-soft` + 深棕描边。danger：陶土橙同构。ghost/subtle 不变。iconOnly 直径 ≥ 44px。 |
| **Card** | 纸色底 + 1px `--border-hairline`；低库存卡：左边 4px 叶绿/陶土色竖条 + 叶形小角标；按压：scale 0.98 + 背景加深 4%。**不用阴影**，分层靠描边。 |
| **Input** | 圆角 12 + 1.5px 描边；focus：叶绿描边 + 2px 外发光（`--accent-sage` 30% 透明度）。`ai-suggested` 状态：蜂蜜色描边 + 右侧小「AI」叶形徽标。错误态：陶土橙文字（PRD 规则不变）。 |
| **Stepper** | 圆形按钮（≥ 44px）+ 深棕描边 + 米白底；数字用铃钱黄高亮 + tabular-nums。 |
| **Sheet** | 顶部圆角 24 + 2px 深棕描边（动森对话框）；顶部手柄改为短粗圆条；遮罩用 `--bg-overlay`。 |
| **Badge** | 圆形/叶形，深棕描边；低库存=陶土橙字+浅底；AI 置信度=蜂蜜色描边。 |
| **EmptyState** | 线稿插画升级为「动森小场景」：木牌 + 小叶片 + 星星，≤ 120px，深棕线稿；保留 1 个主 CTA（PRD 规则）。 |
| **Skeleton** | 纸色块 + 淡入淡出呼吸（200ms），不换样式结构。 |
| **Toast** | 改成动森对话气泡：白底 + 2px 深棕描边 + 底部小三角尾巴；撤销/错误文案规则不变。 |
| **ThemeToggle** | 太阳/月亮圆润图标，深棕描边。 |
