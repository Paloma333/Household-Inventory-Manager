## 14. API 返回的用户可见中文（摘要）

- 认证类：`unauthorized`（英文，前端兜底 `出了点小问题`）
- 商品：`名字不能空` / `日期格式应为 YYYY-MM-DD` / `字段不合法` / `家还没建好，请刷新页面` / `插入失败` / `event 写入失败，已回滚` / `delta 或 absolute 二选一` / `item 不存在` / `更新失败，已回滚事件`
- 规则：`阈值要大于 0` / `阈值太大了` / `这件商品不存在` / `无权限`
- 识别：`sourceType 必须为 receipt/screenshot/camera` / `file 字段缺失或类型不对` / `上传失败` / `识别失败：{msg}` / `task 不存在` / `该批次已确认过`
- 草稿：`草稿不存在` / `只有草稿才能放弃`
- 导出：`format 只支持 csv / json`；文件名 `小家库存-{date}`；CSV 表头 `名称/品牌/数量/单位/包装数量/过期日/分类/创建时间/更新时间/状态`（`已删除` / `在库`）
- 存储：`不支持的图片类型 {mime}（仅 jpg/png/webp/heic）` / `图片太大 {N}MB > 10MB` / `上传失败：{msg}。如果提示 bucket 不存在，请先在 Supabase Dashboard 创建 recognition-images（private, 10MB 限制）。`

---

**语气备注（审校基准）**：
1. 全站用「小家 / 小屋」拟人化自称，不用「本应用 / 系统」。
2. 动作按钮用短口语：`添点东西`、`进小家`、`加进小家`、`去补一补？`。
3. 提示克制、只在该出现时出现（PRD 第 0 页：禁止庆祝式动画 / 彩色卡片墙）。
4. AI 相关不暴露术语：置信度档位只显示 `待确认` 或打勾，不显示 `高置信 / 需修正`。
